# React HOOKS :

- Hooks are functions defined in react so to use them we have to import them.
- Hooks do the job of UI updating.

## useState Hook :
```
import {useState} from 'react';
let [counter, setCounter] = useState(x);
```
where x = any number/string/empty string/obj etc
- counter = variable : it stores the value of the variable (initialized by x)
- setCounter = function : it is used to change/update the value stored in counter.
